---
name: Claude Code vs Cowork vs Chat
description: When to use each platform
type: user
---

**Claude Code (this tool)**
- Writing and editing code with full file access
- Testing code with preview servers
- Complex multi-step dev tasks (build, debug, deploy)
- Need git integration, bash commands, file manipulation
- Working in worktrees or large codebases

**Cowork**
- Real-time collaboration with other people
- Pair programming or live code review
- Shared cursor, shared context, see each other's edits
- When you need multiple people working simultaneously

**Chat**
- Quick questions, brainstorming, research
- No code editing or file access needed
- Explaining concepts, writing copy, planning
- Fast responses, no setup

**Short version:** Code = building things. Cowork = building with others live. Chat = talking about building.
