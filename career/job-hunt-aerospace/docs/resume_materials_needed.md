# Resume Materials Needed

To make the cover-letter side actually good instead of generic, place these somewhere accessible:

## Needed files
- current resume (PDF or DOCX)
- one strong prior cover letter
- optional transcript / portfolio links / LinkedIn summary

## Best location
Put them here:
- `career/job-hunt-aerospace/materials/resume.pdf`
- `career/job-hunt-aerospace/materials/cover_letter_seed.md`

## Why
That gives the agent a stable local source for:
- resume lane tailoring
- project bullet reuse
- company-specific cover letters
- application packet generation
